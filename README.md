# Key LLM Publications

Thirty essential papers, articles and blog posts every practising LLM / agent engineer should know &mdash; from *Attention Is All You Need* to the Model Context Protocol &mdash; each with a plain-language summary, an engineer's interpretation of why it matters, and diagrams of the core idea. Grouped into six themed presentations of five publications each.

**Live index:** https://brendanjameslynskey.github.io/LLM_Hub_Key_Publications/
